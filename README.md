# 与你 · Our Little Story

A watercolor memory game published at https://hajimeru.github.io/.

This repository contains the verified static release files only.

Source: https://github.com/hajimeru/MarryMe/tree/main
Source commit: a5685e1e9983d831218e4355be482795cf74ed6a

To update: build the source project with Node 24 (`npm ci`, `npm run check`, `npm run build`), copy the resulting `dist/` files to this repository, and commit/push to `main`.

GitHub Pages publishes the root of `main`. `.nojekyll` keeps the generated assets unchanged. Music starts after an explicit click; mute preferences are kept in browser storage.
